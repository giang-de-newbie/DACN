III. YÊU C ẦU KỸ THU ẬT 
1. Ch ức năng b ắt buộc 
Chức năng  Mô t ả chi ti ết 
Nhập liệu ngôn ng ữ 
tự nhiên  Người dùng nh ập câu ti ếng Vi ệt tự do (VD: “Nh ắc tôi h ọp nhóm lúc 
10 gi ờ sáng mai ở phòng 302, nh ắc trước 15 phút”)  
Trích xu ất thông tin 
(NLP)  Tự động phân tích và trích xu ất:  
• Tên s ự kiện 
• Thời gian b ắt đầu 
• Địa điểm 
Thời gian nh ắc nhở 
Quản lý s ự kiện Thêm, s ửa, xoá, tìm ki ếm, hi ển thị lịch theo ngày/tu ần/tháng  
Lưu tr ữ cục bộ Dữ liệu được lưu dư ới dạng SQLite ho ặc JSON  
Hệ thống nh ắc nhở Kiểm tra đ ịnh kỳ (mỗi 60 giây), hi ển thị pop-up khi đ ến giờ nhắc 
Xuất/ nh ập dữ liệu Hỗ trợ xuất file .ics ho ặc .json  
 
2. Yêu c ầu về xử lý tiếng Vi ệt 
• Đầu vào: Câu ti ếng Vi ệt tự nhiên, có th ể viết tắt, thiếu dấu 
• Đầu ra:  Dictionary ch ứa 5 trư ờng:  
{ 
 “event”: “h ọp nhóm”,  
 “start_time”: “2025 -11-01T10:00:00”,  
 “end_time”: null,  
 “location”: “phòng 302”,  
 “render_minutes”: 15  
} 
• Yêu c ầu xử lý: 
o Hiểu được các m ẫu như: 10h, 10 gi ờ, 10:30, sáng mai, th ứ Hai t ới, cuối tuần,… 
o Xử lý thời gian tương đ ối (dựa trên datetime.now())  
o Độ chính xác trích xu ất: >= 80% trên 30 test case  
3. Giao di ện ngư ời dùng  
• Yêu c ầu tối thiểu: 
o Ô nh ập văn b ản tự do  
o Nút “Thêm s ự kiện” 
o Bảng lịch (d ạng lư ới hoặc danh sách)  
o Nút S ửa/ Xoá/ Tìm ki ếm 
o Thông báo pop -up khi nh ắc nhở 
IV . HƯ ỚNG D ẪN TRI ỂN KHAI  
1. Giải pháp NLP (5 bư ớc) 
Kiến trúc model NLP đư ợc thiết kế theo mô hình hybrid (k ết hợp rule -based và model -based) đ ể 
đảm bảo hiệu quả cao v ới tài nguyên h ạn chế (không c ần GPU). S ử dụng Underthesea làm thư 
viện chính cho x ử lý tiếng Vi ệt, kết hợp dateutil cho phân tich th ời gian  
• Kiến trúc t ổng quát (V ẽ flowchart)  
[Đầu vào: Câu ti ếng vi ệt] 
 (Preprocessing ) 
[Component 1: Phân đo ạn từ và Ti ền xử lý] → Danh sách t ừ đã chu ẩn hoá  
 (NER Extraction)  
[Component 2: Trích xu ất thực thể] → TIME, LOCATION  
 (Rule -based)  
[Component 3:  Rule -based -extraction] → Sự kiện, Nh ắc nhở 
 (Time parsing)  
[Component 4: Phân tích th ời gian] → Datetime tuy ệt đối 
 (Validation)  
[Component 5: H ợp nhất và x ử lý lỗi] → Đầu ra dictionary ho ặc lỗi 
 
[Core Engine: Lưu s ự kiện] 
o Component 1: X ử lý đặc trưng ti ếng Vi ệt (không d ấu cách)  
o Component 2: Model -based (NER) đ ể nhận diện thực thể 
o Component 3: Rule -based đ ể bắt mẫu cố định 
o Component 4: Chuy ển đổi thời gian tương đ ối 
o Component 5: Ki ểm tra tính h ợp lệ 
Hướng dẫn chi ti ết và c ụ thể 
Bước Mục đích  
1. Phân đo ạn từ và Ti ền xử lý Tách t ừ tiếng Vi ệt và chu ẩn hoá  
2. Trích xu ất thực thể (NER)  Nhận diện TIME, LOCATION t ự động 
3. Rule -based extraction  Bắt mẫu cố định cho s ự kiện, nh ắc nhở 
4. Phân tích th ời gian  Chuy ển TIME thành datetime tuy ệt đối 
5. Hợp nh ất và x ử lý lỗi Ghép k ết quả, kiểm tra h ợp lệ 
 
2. Lưu tr ữ và nh ắc lịch 
• Lưu tr ữ: Dùng sqlite3, lưu start_time dư ới dạng ISO string  
• Nhắc lịch: Dùng thread riêng, ki ểm tra m ỗi 60 giây, so sánh start_time - reminder
